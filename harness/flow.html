Harness agent flow

How /harness <task> runs in herdr: one lead agent coordinates five helper agents, from design doc to an approved pull request for every sub-task.

Who talks to whom

Helpers never talk to each other. Every message goes through the lead, which runs herdr agent prompt and herdr agent read.

Stops early and asks you after 3 failed test runs or 3 review rounds that still have findings.

Where you step in

Design gateApprove, comment, or pick another approach ("go with B").
PR gateOnce per sub-task. Approve, or request changes and the same PR is updated.
Stuck3 failed test runs, or 3 review rounds still finding issues.
