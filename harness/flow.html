Harness agent flow

How /harness <task> runs in herdr: one lead agent coordinates six helper agents, from design doc to an approved pull request for every sub-task.

Who talks to whom

Helpers never talk to each other, except the coder and the area specialists it starts. Every other message goes through the lead, which runs herdr agent prompt and herdr agent read.

Decisions

Helpers never ask you directly. They send ASK with options and a recommendation to the lead; area specialists go through the coder. The lead collects them, plus any agent stuck on a permission prompt, and asks you once in the lead tab as a numbered "Decisions needed" list. Independent work keeps going while you decide.

Where you step in

Design gateApprove, comment, or pick another approach ("go with B").
PR gateOnce per sub-task. Approve, or request changes and the same PR is updated.
Stuck3 failed test runs, or 3 review rounds still finding issues.
